## hey, i'm farhan.

Most of my work lives somewhere between **messy backend logic and pixel-level UI decisions**.

I build web applications, design interfaces, work on healthcare systems, experiment with automation, and occasionally disappear into Roblox Studio to build things in 3D.

I enjoy projects that look simple from the outside but have a lot going on underneath.

That's usually where the fun starts.

> **Good code should work. Good design should get out of the way.**

## a little more about how i work

I like starting with the uncomfortable parts.

The confusing workflow.
The slow page.
The crowded dashboard.
The system that technically works but makes someone click five times to do something simple.

Then I try to make it make sense.

Sometimes that means writing backend logic.

Sometimes it means moving one button.

Sometimes it means deleting half the UI.

And sometimes it means rebuilding the whole thing.
